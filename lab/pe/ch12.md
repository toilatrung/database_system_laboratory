# Chapter 12 — Physical Storage Systems

## 12.1
SSDs can serve as a storage layer between main memory and magnetic disks, keeping some parts of the database (for example, some relations) on SSD and the rest on magnetic disk. Alternatively, SSDs can serve as a buffer or cache for magnetic disks: frequently used blocks live on the SSD layer and rarely used blocks stay on magnetic disk.

### a
Which of the two alternatives would you pick if you must support real-time queries that have to be answered within a guaranteed short time? Explain why.

### b
Which of the two alternatives would you pick for a very large *customer* relation in which only some disk blocks are accessed frequently and the other blocks are rarely accessed?
