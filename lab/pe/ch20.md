# Chapter 20 — Database-System Architectures

## 20.1
Must a multiuser system necessarily be a parallel system? Justify your answer.

## 20.2
On many architectures, atomic instructions such as compare-and-swap and test-and-set also perform a memory fence as part of the instruction. Considering data in shared memory that is protected by a mutex built from such an atomic instruction, explain why executing the memory fence is needed. Also explain what a process should do before it releases a mutex.

## 20.3
Rather than keeping shared structures in shared memory, an alternative architecture keeps them in the local memory of one special process, and other processes reach the shared data through interprocess communication with that process. What would be the disadvantage of this architecture?

## 20.4
For transactional concurrency control, explain the difference between a latch and a lock.

## 20.5
A transaction is written in C with embedded SQL; about 80 percent of its running time is spent in SQL code and the other 20 percent in C code. If parallelism is applied only to the SQL code, how much speedup can one hope for? Explain.

## 20.6
In a shared-memory system, process A updates a data structure and then sets a flag to signal that the update is finished. Process B watches the flag and begins processing the data structure only once it sees that the flag is set.

Explain what can go wrong on a memory architecture in which writes may be reordered, and explain how the sfence and lfence instructions can be used to prevent the problem.

## 20.7
On a shared-memory architecture, why can the time needed to access a memory location depend on which location is accessed?

## 20.8
Most operating systems for parallel machines (i) allocate memory from a local memory area when a process asks for memory, and (ii) try not to move a process from one core to another. Why do these optimizations matter on a NUMA architecture?

## 20.9
Some database operations, such as joins, run much faster when the data (for example, one of the relations being joined) fits in memory than when it does not. Show how this explains *superlinear speedup*, in which an application obtains a speedup larger than the increase in resources given to it.

## 20.10
What is the essential difference between homogeneous and federated distributed database systems?

## 20.11
Why might a client choose to subscribe only to the basic infrastructure-as-a-service model instead of the services offered by the other cloud service models?

## 20.12
Assuming the data reside on external storage, why do cloud-computing services best support traditional database systems by running them in a virtual machine, rather than directly on the provider’s physical machine?
